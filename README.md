# فروشگاه آنلاین ابزار نبهانی

## اجرای محلی
npm install
cp .env.example .env
npm run seed
npm start

## ساخت اولین ادمین
مقدار ADMIN_SETUP_TOKEN را در .env بگذار و برو به:
/setup-admin?token=TOKEN&phone=09xxxxxxxxx

## نکات این نسخه
- دسته‌بندی‌ها الان عکس پروفایل دارند (پنل مدیریت -> دسته‌بندی‌ها -> افزودن/ویرایش)
- جزئیات کامل سفارش (آدرس، گیرنده، اقلام با عکس) در پنل مدیریت -> سفارش‌ها -> جزئیات
- درخواست نصب روی صفحه اصلی گوشی (PWA) فعال است
- برای آیفون: Safari اجازه نصب خودکار نمی‌دهد، فقط راهنمای دستی نمایش داده می‌شود (محدودیت اپل است)
